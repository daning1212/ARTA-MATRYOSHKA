# Healing Arty & Arta 공동개발

## ARTA MATRYOSHKA — 아르타 쉴드 🛡️

**아르타 쉴드: 가짜 성공을 관측하는 오픈소스 방어 실험실.**

공격 도구를 누구나 구할 수 있다면 방어 실험 도구도 누구나 사용할 수 있어야 합니다.
이 첫 버전은 Python 표준 라이브러리만으로 실행하는 **로컬 HTTP 미끼 시뮬레이터**입니다.
운영 서버 보호 제품이 아니며, AI를 속인다는 효과는 아직 검증하지 않았습니다.

## 시작하기

Python 3.10 이상, 추가 패키지 설치 불필요:

```bash
git clone https://github.com/daning1212/ARTA-MATRYOSHKA-.git
cd ARTA-MATRYOSHKA-
python -m arta
```

- 미끼 공간: http://127.0.0.1:8080
- 관측 기록: http://127.0.0.1:8081/events
- 기록 무결성 확인: http://127.0.0.1:8081/health
- 종료: Ctrl+C

두 포트 모두 **127.0.0.1에만 바인딩**됩니다. 인터넷에 공개하거나 프록시로 노출하지 마세요.
브라우저로 `/admin`, `/backup`을 방문하고 관측 기록을 확인할 수 있습니다.

## 그림자 세계 실험

```bash
curl -c cookies.txt http://127.0.0.1:8080/admin
curl -b cookies.txt -H 'Content-Type: application/json' \
  -d '{"maintenance":true}' http://127.0.0.1:8080/api/settings
curl -b cookies.txt http://127.0.0.1:8080/api/settings
```

가짜 관리자 역할이 표시되고 가짜 설정만 바뀝니다. 같은 세션에서는 다시 조회해도 변경 상태가 유지됩니다.
실제 계정, 실제 관리 권한, 실제 서버 설정에는 연결되지 않습니다. 세션은 15분 후 만료되며 재시작하면 초기화됩니다.
`cookies.txt`는 실험 후 삭제하세요.

## 구현된 기능

- 관리자 방, 자료실, 세션별 가짜 설정 및 미끼 자료 식별 표식.
- 접속 IP당 60초에 최대 30회 허용. 초과 요청에 429 응답.
- 요청 본문 최대 4 KiB, 클라이언트·세션 최대 1,000개.
- 최근 10,000개 이벤트를 SQLite에 보관, 관측 API에서는 최근 100개 조회.
- 요청 본문·쿼리·암호·인증 헤더·원본 쿠키는 저장하지 않음.
- 알려진 방 이름, 접속 주소, 시간, 응답 상태, 세션 표식의 해시를 기록.
- 해시 연결로 보관된 기록의 변경 여부 확인.

## 한계와 보안 경계

미끼와 관측 포트는 분리되어 있지만 **동일 프로세스 및 동일 OS 사용자**로 실행됩니다.
운영용 네트워크 격리, 외부 기록 저장소, 불변 감사 로그는 아직 구현하지 않았습니다.
기록 파일 접근자는 해시 전체를 다시 계산할 수 있으므로 해시 연결은 공격자에 대한 무결성 보장이 아닙니다.
이벤트 개수는 제한되지만 장기 디스크 용량의 엄격한 상한은 아닙니다.

요청 제한은 이 미끼 서버에만 적용됩니다. 실제 로그인, 분산 공격, 오프라인 암호 추측,
와이파이 공격, DDoS를 보호하지 않습니다. 순차 HTTP 서버라 느린 연결에도 가용성 한계가 있습니다.
관측 포트에는 인증이 없으므로 로컬 사용자와 프로그램이 기록을 볼 수 있습니다.
세션 쿠키는 HTTP 로컬 데모용이며 운영 인증 수단이 아닙니다.

실제 서버의 비밀·개인정보를 미끼에 넣지 마세요. 방문자의 IP는 신원 증명이 아닙니다.
실험 종료 뒤 기록이 필요 없으면 `data/`를 삭제하세요. 자신이 소유하거나 명시적으로 허가받은
격리 실험 환경에서만 사용하세요.
