# ARTA-MATRYOSHKA

**가짜 자산과 겹겹이 이어지는 탐색 경로에서 자동화된 침입자가 어떤 선택을 하는지 연구합니다.**

연구 아이디어와 로컬 실험용 프로토타입입니다. 실제 AI 공격자에 대한 방어 효과는 검증되지 않았으며, 운영용 보안 제품이 아닙니다.
다른 개발자와 보안 연구자가 영감을 얻고 독립적으로 검증·확장할 수 있도록 공개합니다.
비판, 재현 실험, 개선 제안과 효과가 없었던 결과도 환영합니다.

**한국어** | [English](README.en.md)

## 왜 만들었는가

접근 차단 여부만으로는 침입자의 탐색과 판단을 모두 설명할 수 없습니다.
가짜 시스템을 진짜로 판단하는 조건은 무엇일까요?
가짜라는 의심이 생겨도 탐색을 계속할까요?
이때 시간·재방문·검증 행동의 변화를 측정할 수 있을까요?

ARTA-MATRYOSHKA는 이 질문들을 실험 가능한 형태로 만드는 프로젝트입니다.

## 핵심 아이디어

의미 있는 목표처럼 보이는 가짜 자산과 단서를 제공하고,
탐색이 진행될수록 다음 가짜 공간으로 이어지는 마트료시카형 기만 구조를 연구합니다.
실제 보호 자산은 독립적인 인증·접근통제·격리 경계로 구분되어야 합니다.

현재 구현은 JSON HTTP API로 표현한 **유한한 가짜 세계**입니다.
가짜 복구 코드로 상태를 바꾸고, 프리셋에 따라 추가 문·가짜 출구·설정 복제본을 탐색합니다.
무한 중첩, 공격자의 이탈 방지, 실제 권한 상승이나 샌드박스 탈출을 구현한 것은 아닙니다.

## 현재 상태

| 구분 | 저장소에서 확인할 수 있는 내용 |
|---|---|
| 구현됨 | localhost 미끼 API, 세션별 가짜 상태, 6개 시나리오 프리셋, 요청·세션 예산 ([세계](arta/world.py), [HTTP](arta/web.py)) |
| 구현됨 | 별도 수집기 프로세스, 인증된 기록 조회, SQLite 이벤트 저장과 해시 연결 검사 ([수집기](arta/collector.py), [저장](arta/audit.py)) |
| 구현됨·별도 실험 | 고정 스크립트 탐색 비교, 합성 자료 수집·일반 SHA-256 PoW·요청 제한 비교. PoW는 미끼 세계에 미통합 ([탐색](arta/experiment.py), [수집 비교](arta/collectionbench.py)) |
| 공개된 예비 결과 | 기능 테스트, 합성 자료 실험 보고서와 원본 JSON이 있음. 실제 AI 에이전트·실제 공격자의 행동 실험과는 구분 |
| 향후 검증 과제 | 미끼 유무 대조군, 실제 AI의 탐지·우회·포기 행동, 장기 반복과 다른 환경에서의 재현 |
| 아이디어·미구현 | 강력한 OS·네트워크 격리, 운영 연동·외부 알림·두 사람 승인·VDF·시각적 대시보드. 구현 일정은 확정하지 않음 |

고정 Python 스크립트의 계산 비용·수집량 차이는 AI 기만 효과나 실제 자산 보호의 증거가 아닙니다.
현재 `baseline`도 단순 미끼이므로 **미끼가 없는 대조군이 아닙니다**.
합성 보호 경로가 항상 거부되도록 만든 실험의 수집량 0도 방어 효과로 해석하지 않습니다.

## 검증하고 싶은 가설

- 미끼가 없는 조건보다 목표 도달·탐색 시간이 늘어나는가?
- 가짜 자산을 실제 목표로 오인하는 비율과 재방문 비율이 달라지는가?
- AI 에이전트가 기만 단서를 탐지하고 검증·우회·이탈하는 조건은 무엇인가?
- 기만 구조의 기록이 방어자에게 유의미한 관찰 신호를 제공하는가?

같은 합성 목표와 시간·요청·자원 예산에서 비교하고, 정상 사용자 부담과 방어자 비용도 함께 측정해야 합니다.
이는 연구 질문이며 현재 달성한 성과가 아닙니다. [설계와 평가 계획](docs/DESIGN.md)

## 로컬 실행

Python 3.10 이상, 표준 라이브러리만 사용합니다.
먼저 아래 한계를 확인하고, 허가된 로컬 격리 환경에서 실행하세요.

```bash
git clone https://github.com/daning1212/ARTA-MATRYOSHKA.git
cd ARTA-MATRYOSHKA
python -m arta
```

미끼 API: http://127.0.0.1:8080 · 다른 터미널에서 기록 조회: `python -m arta.observe` · 종료: Ctrl+C.
기본 실행은 900초 후 종료됩니다. [시나리오·응답 예제·상한](docs/REFERENCE.ko.md#실행)

기능 테스트: `python -m unittest discover -s tests -v`. 기능 테스트 통과는 보안 효과 검증이 아닙니다.

## 미검증 항목과 이유

- 방화벽·인증·접근제어·네트워크 분리를 대체하지 않습니다. 실제 공격자와 AI에 대한 효과는 반복 실험으로 검증해야 합니다.
- localhost 바인딩과 별도 프로세스는 OS 샌드박스가 아닙니다. 현재 코드는 같은 OS 계정의 파일 접근이나 외부 통신을 OS 수준에서 차단하지 않습니다.
- 허가된 로컬 격리 환경과 합성 자료만 사용하세요. 실제 개인정보·운영 계정·외부 서비스·제3자 시스템을 연결하지 마세요. 인터넷이나 리버스 프록시로 공개하지 마세요.
- 신뢰할 수 없는 공격 도구를 실행하기 전에는 별도의 격리 경계를 구성하고 실제 차단 여부를 검증해야 합니다.
- UDP 기록은 유실될 수 있고 해시 연결은 전체 재작성·삭제를 막지 못합니다. 일반 해시 PoW는 병렬화 가능하며 사용자 인증이 아닙니다.
- 복잡한 기만 구조는 유지보수 비용과 새로운 취약점을 만들 수 있습니다. 운영 안전·가용성·정상 사용자 부담은 미검증입니다.
